## Project Overview 
Modern Furniture UI Challenge 7 is a responsive front-end web application that showcases a modern furniture store with a clean, elegant, and user-friendly interface. The project focuses on creating an attractive shopping experience where users can browse stylish furniture collections through a well-structured and visually appealing layout.

The main goal of this project was to strengthen my skills in React, TypeScript, and responsive web design by building reusable components and implementing a modern user interface. The application emphasizes simplicity, accessibility, and responsiveness to ensure a seamless experience across desktop, tablet, and mobile devices.

## Commands used to install and setup
'''bash
git clone <repo-URL> 
cd UI-Challenge7
npm install 
npm run dev
'''
